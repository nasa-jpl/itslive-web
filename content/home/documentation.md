### Open source tools

<div class="doc-grid">
  <a class="doc-card" href="https://github.com/leiyangleon/autoRIFT" target="_blank" rel="noopener">
    <h4>autoRIFT</h4>
    <p>A highly accurate and efficient algorithm for finding the pixel displacement between two radar or optical images.</p>
  </a>
  <a class="doc-card" href="https://github.com/nsidc/NSIDC-Data-Tutorials/blob/main/notebooks/itslive/itslive-notebook.ipynb" target="_blank" rel="noopener">
    <h4>NSIDC notebook</h4>
    <p>A Jupyter notebook to search and download ITS_LIVE scene-pair velocity.</p>
  </a>
  <a class="doc-card" href="https://github.com/chadagreene/ITS_LIVE" target="_blank" rel="noopener">
    <h4>Chad Greene's Matlab collection</h4>
    <p>Matlab functions for accessing, analyzing, and plotting ITS_LIVE velocity data, including flowlines and ice-flow maps.</p>
  </a>
  <a class="doc-card" href="https://staging.nsidc.org/apps/itslive-search/docs" target="_blank" rel="noopener">
    <h4>ITS_LIVE API</h4>
    <p>An API for searching ITS_LIVE scene-pair velocities.</p>
  </a>
  <a class="doc-card" href="https://github.com/leiyangleon/Geogrid" target="_blank" rel="noopener">
    <h4>Geogrid</h4>
    <p>A Python module for precise mapping between (pixel index, pixel displacement) and (geolocation, motion velocity) coordinates.</p>
  </a>
  <a class="doc-card" href="https://e-marshall.github.io/itslive/intro.html" target="_blank" rel="noopener">
    <h4>Emma Marshall's ITS_LIVE tutorial</h4>
    <p>A Jupyterbook tutorial for accessing multi-dimensional ITS_LIVE data with xarray.</p>
  </a>
  <a class="doc-card" href="https://mappin.itsliveiceflow.science/" target="_blank" rel="noopener">
    <h4>Jacob Fahnestock's velocity webapp</h4>
    <p>A serverless React-Leaflet website to plot and share ITS_LIVE data.</p>
  </a>
</div>

### How to Cite

<div class="cite-box">
  <p>The recommended citation for the <i>Regional Glacier and Ice Sheet Surface Velocities</i> is:<br/>
  "Velocity data generated using auto-RIFT (Gardner et al., 2018) and provided by the NASA MEaSUREs ITS_LIVE project (Gardner et al., 20XX)."</p>
  <p>The recommended citation for the <i>Antarctic Ice Sheet Elevation Change</i> data is:<br/>
  "Antarctic Ice Sheet Elevation Change data (Nilsson et al., 2022) provided by the NASA MEaSUREs ITS_LIVE project (Nilsson et al., 20XX)."</p>
</div>

Velocities: Version 1. Data archived at National Snow and Ice Data Center; https://doi:10.5067/6II6VW8LLWJ7.</p>

<p>Gardner, A. S., G. Moholdt, T. Scambos, M. Fahnstock, S. Ligtenberg, M. van den Broeke, and J. Nilsson, 2018: Increased West Antarctic and unchanged East Antarctic ice discharge over the last 7 years, Cryosphere, 12(2): 521–547, https://doi:10.5194/tc-12-521-2018.</p>

<p>Nilsson, J., Gardner, A., &amp; Paolo, F. [update to time of data download]: MEaSUREs ITS_LIVE Antarctic Grounded Ice Sheet Elevation Change, Version 1, https://doi.org/10.5067/L3LSVDZS15ZV.</p>
